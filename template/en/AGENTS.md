# For agents

This folder is an Obsidian vault and also the user's persistent memory.

Before reading or writing anything here, read `CLAUDE.md` in the root and follow its rules. That file defines the folder layout, the frontmatter schema, the operations and the prohibitions; it is the single source of truth for Claude Code, Codex and every other agent.

Quick reminder:

- For a question about past work, read `index.md` first, then the relevant pages.
- For the memory of the project you are working in, run `~/.vault-memory/bin/vm context`.
- Do not write secrets (keys, tokens, passwords).
- Do not edit `index.md` or `log.md` by hand.
